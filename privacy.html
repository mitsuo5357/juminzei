プライバシーポリシー

「市県民税 計算支援（令和9年度）」（以下「本アプリ」）における、利用者の情報の取扱いについて定めます。

1. 取得する情報

本アプリは、利用者の個人情報を取得・収集しません。氏名、住所、電話番号、メールアドレス、位置情報、端末の識別子、連絡先などへのアクセスも行いません。ただし、アプリ内購入をしたときは、購入の確認のために「3. アプリ内購入」の情報を扱います。

2. 入力した内容の扱い

  • 収入・控除などの入力内容は、利用者の端末の中だけで計算します。開発者や第三者のサーバーへ送信することはありません。
  • 住所地として選んだ市区町村（税率を決めるためのもの）は、設定として端末内（ブラウザのローカルストレージ）に保存します。外部には送りません。位置情報は使いません。
  • 「入力内容をこの端末に自動で保存する」が有効な場合、入力内容は端末内（ブラウザのローカルストレージ）に保存されます。メニューの設定でオフにしたり、「すべての入力を消す」で削除したりできます。アプリをアンインストールすると削除されます。
  • 「ファイルに保存」「結果を送る」「印刷・PDFで保存」を使った場合、保存先・送信先は利用者が選んだ場所（端末のフォルダや、選んだアプリ）になります。

3. アプリ内購入（税額シミュレーション）

  • 税額シミュレーション（節税のヒント）は、Google Play のアプリ内購入です。支払いは Google Play が扱い、開発者がクレジットカード番号などの支払い情報を受け取ることはありません。Google による情報の扱いは Google プライバシー ポリシー をご覧ください。
  • 購入したとき、および購入の確認・復元をするときは、購入ごとの番号（購入トークン）とアイテムの ID を、開発者が運営する購入確認サーバーに送ります。サーバーは Google Play Developer API に購入の状態を問い合わせて購入を確定（承認）し、結果をアプリに返します。
  • 購入確認サーバーは Cloudflare, Inc. の Cloudflare Workers で動いています。サーバーは購入トークンを保存しません。通信の際、Cloudflare がセキュリティ等の目的で接続元のIPアドレスなどを記録することがあります（Cloudflare のプライバシーポリシー）。
  • 入力した収入・控除などの内容は、購入確認サーバーにも送りません。
  • 確認できた購入は、オフラインでも使えるように端末内（ローカルストレージ）に保存します。

4. 広告・アクセス解析

本アプリは広告を表示せず、アクセス解析ツールや利用状況の収集も行いません。

5. 配信サーバーについて

本アプリの画面とプログラムは GitHub Pages（GitHub, Inc.）から配信されます。配信の際、GitHub がセキュリティ等の目的で接続元のIPアドレスなどを記録することがあります。詳しくは GitHub のプライバシーに関する声明 をご覧ください。

6. 行政機関との関係

本アプリは個人が作成したもので、国・都道府県・市区町村などの行政機関の公式アプリではなく、行政機関とは関係がありません。計算結果は参考値です。
